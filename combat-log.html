Combat Log

Upload an Ikusa or CoGM Logger export to see kill/death detail from one player's viewpoint.
Ikusa and CoGM Logger are third-party combat loggers some members run alongside BDO — they watch the game's network traffic and write a plain-text .log file of every kill/death that player's client saw ("PlayerA has killed PlayerB from GuildName"). CoGM's export additionally tags each side with its in-game character name in parentheses — both formats are recognized automatically. Drop a file below to parse it — everything happens locally in your browser; nothing is uploaded anywhere.
⚠ This only reflects one client's view, not a full war roster — it's not a substitute for /addwar or the official War Scores record, just a detail lens on individual engagements.
